📐 Dik Üçgende Trigonometri & Birim Çember

10. Sınıf 1. Tema Temel Kazanım Anlatımı[cite: 1, 2]

Bir dik üçgende açının konumuna göre kenarlar adlandırılır. Hipotenüs dik açının karşısındaki en uzun kenardır[cite: 1, 2].

sin(α) = Karşı / Hipotenüs
cos(α) = Komşu / Hipotenüs
tan(α) = Karşı / Komşu = sin(α) / cos(α)
cot(α) = Komşu / Karşı = cos(α) / sin(α)[cite: 1, 2]
Çözümlü Sınav Örneği:

Soru: Hipotenüsü $10$ cm ve $\alpha$ açısının karşısındaki dik kenar $6$ cm olan dik üçgende $\sin\alpha$ ve $\cos\alpha$ değerlerini hesaplayınız[cite: 1, 2].

Çözüm Adımları:
1. Pisagor teoremi uygulanarak komşu kenar ($x$) bulunur: $x^2 + 6^2 = 10^2 \implies x = 8$ cm[cite: 1, 2].
2. $\sin\alpha = \frac{\text{Karşı}}{\text{Hipotenüs}} = \frac{6}{10} = \frac{3}{5}$[cite: 1, 2].
3. $\cos\alpha = \frac{\text{Komşu}}{\text{Hipotenüs}} = \frac{8}{10} = \frac{4}{5}$[cite: 1, 2].

⚡ Sinüs ve Kosinüs Teoremleri

Sinüs Teoremi: a / sin(A) = b / sin(B) = c / sin(C) = 2R[cite: 1, 2]
Kosinüs Teoremi: a² = b² + c² - 2bc · cos(A)[cite: 1, 2]

Kullanım Alanı: Üçgen dik üçgen olmadığı durumlarda kenar veya açı hesaplarken bu teoremler kullanılır[cite: 1, 2].

📍 Üçgenin Yardımcı Elemanları ve Merkezleri

  • İç Açıortay: Karşı kenarı yan kenarlar oranında böler ($BD/DC = AB/AC$)[cite: 1, 2].
  • Ağırlık Merkezi (G): Kenarortayların kesişim noktasıdır. Köşeye 2k, tabana k ($2:1$) uzaktadır[cite: 1, 2].
  • Çevrel Çemberin Merkezi: Kenar orta dikmelerin kesiştiği noktadır[cite: 1, 2].
  • Diklik Merkezi (H): Yüksekliklerin kesişim noktasıdır[cite: 1, 2].

N = p₁ᵃ · p₂ᵇ · p₃ᶜ ise Pozitif Bölen Sayısı = (a+1)(b+1)(c+1)[cite: 1, 2]
a · b = EBOB(a,b) · EKOK(a,b)[cite: 1, 2]

ƒ(x) Karesel Fonksiyonlar ve Parabol

f(x) = ax² + bx + c (a ≠ 0)
Tepe Noktası T(r, k): r = -b / (2a), k = f(r)[cite: 1, 2]

a > 0 ise kollar yukarı (minimum nokta), a < 0 ise kollar aşağı doğrudur (maksimum nokta)[cite: 1, 2].

⌘ Sayma, Kombinasyon ve Algoritmalar

Permütasyon: P(n,r) = n! / (n-r)![cite: 1, 2]
Kombinasyon: C(n,r) = n! / [r!(n-r)!][cite: 1, 2]

Akış şemalarında oval (başla/bitir), paralelkenar (giriş/çıkış), dikdörtgen (işlem) ve eşkenar dörtgen (karar) sembolleri kullanılır[cite: 1, 2].

⌖ Analitik Geometri (Nokta ve Doğru)

Eğim (m) = (y₂ - y₁) / (x₂ - x₁)[cite: 1, 2]
Paralel: m₁ = m₂ | Dik: m₁ · m₂ = -1[cite: 1, 2]
